# Contributing to OnboardX

Thanks for your interest in improving OnboardX!

## Getting started

1. Fork the repo and clone your fork.
2. Follow the [Quick start](README.md#quick-start) to run the app locally.
3. Create a branch: `git checkout -b my-change`

## Making a change

- Keep pull requests small and focused on one thing.
- Test your change locally, including `/api/health` and the ask examples in the README.
- Don't commit your `.env` file.
- Describe what you changed and why in the pull request.

## Reporting bugs

Open an issue with the steps to reproduce, what you expected, what happened,
your Operating System, Node version and Ollama model.

## Suggesting features

Open an issue first so we can discuss it before you start building.
