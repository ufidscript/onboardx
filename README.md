## Why OnboardX
The problem: communities lose decisions and context when leaders change.

## Features
- Save handover notes (decisions, lessons, unfinished work)
- Ask questions and get source-backed answers
- Generate an editable, cited handover draft
- Runs fully locally (your data never leaves your machine)
